4

How the service grows

We start with intelligence only, and move closer to bookings only when each gate is passed (slide 13).

Now · months 0–12

Intelligence only

Traveler app, hotel dashboard, planner, API and reports. No bookings, no commission.

Gate: 20 paying hotels, 80% still subscribed after 3 months
Months 12–24

Referral

Travelers can tap through to a hotel's own booking page. We share referral revenue, never sell the room.

Gate: clicks that measurably turn into bookings
Month 24+

Booking layer for partners

A white-label booking API that travel agencies and hotels run under their own name.

Gate: enough volume, permits in place, funding
